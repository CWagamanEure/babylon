Pooled-wallet Efron top-30 majors backtest¶

This notebook reconstructs the current best defensible baseline from validated artifacts: prior-three-month pooled-wallet capped daily-PnL t-stat, t-to-z empirical-Bayes p_informed, monthly top 30, BTC/ETH/SOL/HYPE, fixed $5k entries, one concurrent position per wallet×coin, $50k per-coin cap, 8-hour exit, and 5.5 bp cost.

It does not rerun the expensive selector or data ingest. It rebuilds the globally chronological capacity book from frozen entries and asserts exact agreement with the audited report before computing EDA. Consensus/opinion trading and the >500-fills/day screen are excluded. The eight folds are burned; all performance statistics here are descriptive, not fresh OOS evidence.

2. Daily equity conventions and headline statistics¶

Closed-trade PnL is credited on the 8-hour exit UTC day. The daily frame contains every calendar day from 2025-11-01 through 2026-06-30, including zero-PnL days. Sharpe and Sortino use $\sqrt{365}$ annualization and are descriptive within this frozen horizon. Sortino's denominator is the root mean square of min(daily PnL, 0) over the full calendar. Drawdown begins from zero equity.

calendar = pd.date_range('2025-11-01', '2026-06-30', freq='D', tz='UTC')
daily = trades.groupby('exit_day')[['gross_usd', 'net_usd']].sum().reindex(calendar, fill_value=0.0)
daily.index.name = 'day'
daily['equity'] = daily['net_usd'].cumsum()
running_peak = np.maximum.accumulate(np.r_[0.0, daily['equity'].to_numpy()])[1:]
daily['drawdown'] = daily['equity'] - running_peak
daily['rolling_30d_pnl'] = daily['net_usd'].rolling(30, min_periods=1).sum()
daily['rolling_30d_sharpe'] = (
    daily['net_usd'].rolling(30, min_periods=15).mean()
    / daily['net_usd'].rolling(30, min_periods=15).std(ddof=1) * np.sqrt(365)
)

def exposure_stats(cap):
    events = [(int(t), 1) for t in cap['ts']] + [(int(t) + wc.HOLD_MS, -1) for t in cap['ts']]
    events.sort(key=lambda x: (x[0], x[1]))  # exits before simultaneous entries
    start = int(pd.Timestamp('2025-11-01', tz='UTC').timestamp() * 1000)
    end = int(pd.Timestamp('2026-07-01', tz='UTC').timestamp() * 1000)
    current = maximum = area = 0
    last = start
    for ts, delta in events:
        ts = min(max(ts, start), end)
        area += current * (ts - last)
        current += delta
        maximum = max(maximum, current)
        last = ts
    area += current * (end - last)
    return area / (end - start) * wc.UNIT_USD, maximum * wc.UNIT_USD

avg_exposure, max_exposure = exposure_stats(capacity)
mu = daily['net_usd'].mean()
sd = daily['net_usd'].std(ddof=1)
downside = np.sqrt(np.mean(np.minimum(daily['net_usd'], 0.0) ** 2))
positive_trade_pnl = trades.loc[trades['net_usd'] > 0, 'net_usd'].sum()
negative_trade_pnl = -trades.loc[trades['net_usd'] < 0, 'net_usd'].sum()
active_days = daily['net_usd'] != 0

missing_n = int((~capacity['supported']).sum())

Reading the notebook correctly¶

  • The equity curve is a fixed-$5k, closed-trade accounting curve—not returns on a continuously reinvested fund.
  • Sharpe and Sortino include zero-PnL calendar days and use exit-day attribution. They are descriptive and sensitive to the selected horizon.
  • Fifteen capacity-accepted entries have unavailable outcomes and are omitted from the headline PnL statistics. May breaches the registered per-fold missingness limit, and the registered ±2,000 bp stress can flip the absolute sign.
  • The strategy has a positive mean but a slightly negative median and limited coin breadth. Tail, HYPE, and wallet concentration diagnostics should be read alongside the headline Sharpe.
  • The folds and this strategy family have been repeatedly inspected. Nothing in this notebook is fresh OOS evidence or permission to deploy.
